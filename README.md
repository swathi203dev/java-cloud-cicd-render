# SWATHI.DEV - Java Cloud CI/CD Deployment

## Project Overview
A Java Spring Boot application built using Maven,
containerized using Docker, and deployed through
a Jenkins CI/CD pipeline.

## Technologies
- Linux
- Git and GitHub
- Java
- Maven
- Docker
- Docker Hub
- Jenkins
- Render

## CI/CD Workflow
GitHub -> Jenkins -> Maven Build and Tests
-> Docker -> Docker Hub -> Render

## Features
- Java web application
- Automated Maven tests
- Docker containerization
- Docker Hub image publishing
- Jenkins pipeline automation
- Render cloud deployment
- Automated deployment trigger
